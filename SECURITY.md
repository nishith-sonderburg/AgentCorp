# Security and limitations

Local-only prototype. Do not expose to LAN or Internet. No user authentication, TLS, multi-tenant isolation or production rate limiting. Host/origin checks, JSON-only requests, single concurrent mission, bounded request size, security headers and rotating telemetry reduce local risks. Browser inline script/style allowances remain. Local processes can access the service. Provider outputs are untrusted and may contain prompt injection or hallucinations; no autonomous tools or execution are granted. Goals and preceding reports are transmitted to OpenRouter and its model providers; avoid confidential input. Credentials are environment-only. Logs exclude prompts and keys by design but should remain private. Provider usage may be absent. Report issues privately to the maintainer; contact channel to be established before publication. No external penetration test performed.
